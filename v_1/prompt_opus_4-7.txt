- basic python: python syntax, types, variables, operators, built-in types, built-in data structures (e.g. lists, dictionaries), indexing and slicing, if-else statements, loops (e.g. for, while), functions, etc
- useful python: iterating over folders, copying files, showing how to automate boring stuff, etc.
  (basic python and useful python together: 180 minutes)
  i want to use well explained and maybe also image enriched jupyter notebooks. if images are taken from extern sources, they need to be properly cited (the source must be clear)
  I want to alternatingly show live coding and let the students do exerexercises (maybe 20 minutes of life coding, 20 minutes of exercising)
